# Historial de versiones de Q&A Study

La numeración es la misma para la app de PC (Windows/Mac) y la de celular. En la app, tocá el número de versión (abajo a la derecha del menú) para ver esta lista.

| Versión | Fecha | Cambios |
|---|---|---|
| **2.1** | 19/11/2026 | Celular: la partida se guarda sola si cambiás de app o la cerrás, y al volver podés continuarla (el timer se pausa). Número de versión en el menú (PC y celular). |
| **2.0** | 19/11/2026 | Versión para celular (Android y iPhone): instalable y sin internet. Suma pegar preguntas como texto, editar bloques y exportar una copia de seguridad. |
| **1.3** | 19/11/2026 | Porcentaje de preguntas por tema (y para todo el bloque) en "Ver bloques cargados". La app pasa a llamarse Q&A Study. |
| **1.2** | 19/11/2026 | Importar un bloque que ya existe agrega solo las preguntas nuevas y descarta las repetidas. |
| **1.1** | 18/11/2026 | Versión para Mac. |
| **1.0** | 18/11/2026 | Primera versión para Windows: Multiple Choice y Desarrollo, timer, importar preguntas, carga manual, bloques guardados y vista de bloques. |
